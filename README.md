# coriolis-idealised

Payu configurations for the decoding-om3 page "Choosing a Coriolis scheme in MOM6".
Local repository (no remote yet). Base case on `main`: the Phase 1 toy, an 8x8 doubly
periodic one-layer f-plane ocean run for one 1 s step with the released ACCESS-OM3
mom6-solo (access-om3/2026.05.004, MOM6 d11a149). Sweeps are generated from this
commit with the ACCESS Experiment Generator (YAML in ../../sweeps/).
